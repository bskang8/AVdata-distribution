## 핵심 아이디어

모델이 전체적으로 양호한 성능을 보여도, **특정 서브그룹(슬라이스)에서 체계적으로 실패**하는 경우가 있다. Domino는 이런 실패 슬라이스를 cross-modal embedding(이미지+텍스트)과 언어 모델을 결합하여 **자동으로 발견하고 자연어 설명을 생성**한다.  
기존 핸드크래프트 방식 대비 10배 이상 많은 체계적 오류 패턴을 발견할 수 있으며, 의료 영상·자연어처리 등 다양한 도메인에서 검증됨.

### 알고리즘: 슬라이스 발견 3단계

```
① Embedding
   이미지 + 텍스트를 공통 임베딩 공간으로 매핑 (CLIP 활용)
        ↓
② Error-Aware Clustering
   오류율이 높은 영역을 중심으로 임베딩 공간 클러스터링
   → 오류가 밀집된 클러스터 = "체계적 실패 슬라이스"
        ↓
③ Natural Language Description
   GPT 계열 LM으로 각 슬라이스의 공통 속성 추출 → 자연어 설명 생성
   예: "야간 + 역광 + 보행자 있음" → Recall 43% 하락 슬라이스
```

### 핵심 발견

| 분석 단위 | 오류율 |
|---------|--------|
| 전체 모델 평균 | 8% |
| Domino 발견 최악 슬라이스 | 43% |
| 기존 핸드크래프트 슬라이스 | 15~20% |

→ 전체 지표가 양호해도 **특정 시나리오에서 5배 이상 오류율 급증** 가능  
→ Domino는 핸드크래프트 방식보다 10배 많은 슬라이스 발견

### 슬라이스 발견 메커니즘 (수식)

오류율 가중 혼합 가우시안 모델(Mixture of Gaussians):

```
슬라이스 점수 = P(error | cluster_k) × log P(x | cluster_k)

높은 슬라이스 점수 = 오류율 높음 AND 임베딩 밀집 (명확한 패턴 존재)
```

## 장단점

**장점**
- 사전 정의 없이 데이터 기반으로 실패 슬라이스 자동 발견
- 자연어 설명 생성으로 결과를 비전문가도 이해 가능
- Cross-modal embedding 덕분에 이미지·텍스트 중 어느 쪽 신호도 활용
- 핸드크래프트 기반 분석보다 망라적이고 재현 가능

**단점**
- CLIP 임베딩 품질에 결과가 크게 의존 (도메인 특화 임베더 필요할 수 있음)
- 슬라이스가 너무 많이 나올 경우 우선순위 판단이 추가로 필요
- 오류 레이블(ground truth)이 필요 → 라벨 없는 탐색 단계에는 적용 어려움
- LM 설명 생성이 슬라이스 내용을 오해할 가능성 존재

## 프로젝트 적용 포인트

### Gap-4 연결

현재 검색 시스템의 Recall@5 저하 원인이 특정 시나리오(야간/우천/교차로)에 집중되어 있는지 Domino 방식으로 자동 진단 가능.  
SANFlow가 "밀도 갭(density gap)"을 식별한다면, Domino는 "성능 갭(performance gap)"을 식별한다. 두 신호를 결합하면 수집 우선순위가 명확해진다.

**두 신호 결합 전략:**
```
밀도 낮음 (SANFlow) AND Recall 낮음 (Domino) → 최우선 수집 대상
밀도 낮음 AND Recall 높음                    → 난이도 높지만 모델이 처리 가능
밀도 높음 AND Recall 낮음                    → 데이터는 있지만 품질 문제
밀도 높음 AND Recall 높음                    → 현재 강점 영역 (수집 불필요)
```

**구현 아이디어 (EXP-003 Phase 0):**
```python
# Step 1: 83k 쿼리 캡션 → CLIP 임베딩
# Step 2: 각 쿼리의 Recall@5 계산 (현재 검색 시스템 기준)
# Step 3: Domino 방식 오류율 가중 클러스터링
# Step 4: 실패 슬라이스에 자동 설명 생성 (GPT 활용)
# Step 5: 발견된 슬라이스 = Gap-4 수집 타겟으로 등록
```

### Gap-1 연결

검색 시스템의 쿼리 이해 실패(Gap-1)와 Domino 슬라이스가 겹칠 경우, 해당 슬라이스는 데이터 문제 + 모델 문제가 중첩된 복합 케이스로 분류.
